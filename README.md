# Kickstarter → Telegram

Основной источник: новые физические товары Kickstarter, Technology → Newest.
Проверенная дата `launched_at`, активная кампания, запуск не более 14 дней назад.
Свежесть важнее количества спонсоров. Старые карточки в SQLite перепроверяются
перед отправкой. Modian, Xiaomi и Made-in-China отключены в этом профиле.
География Kickstarter международная: страна автора не доказывает производство в Китае.

Пост: 🚀 название модели, до трёх подтверждённых фактов по-русски, статус,
«Расчет поставки - @stepan_business». Без исходной рекламной строки, источника
в подписи и выдуманной цены. Факты формируются по словарю, без LLM и платных API.
Неизвестные категории и неоднозначные свойства пропускаются с причиной в отчёте.

Фото: обложка и изображения только из истории этой кампании. Динамическая
галерея загружается Playwright. Если история не загрузилась, товар пропускается:
одна найденная обложка не считается доказательством отсутствия других фото.
Далее проверяются размеры, доступность, одинаковые изображения; альбом до 5 фото.
Публичная доступность фото не означает автоматически наличие лицензии.

## Установка в существующий проект

Запустите START.command, выберите обновление установленного проекта, укажите
репозиторий sss1dxx/china-novelties-telegram и GitHub-токен с правами repo/workflow.
Токен вводится только в локальную форму, не в чат. Telegram Secrets и ветка
parser-state сохраняются. Установщик переключает источники на Kickstarter,
включает workflow и запускает send. Проверяйте sent в отчёте запуска.

Или обновите файлы репозитория, затем Actions → Kickstarter new products →
Run workflow → preview (без отправки) / send (публикация в существующий канал).
Cron: 17-я минута каждого часа. GitHub может задерживать запуски.
Первичное наполнение: до 24 товаров суммарно с сохранением прогресса, затем
не более одного поста за запуск и 24 в сутки. Если подходящих новинок нет,
публикации нет. Никаких старых товаров ради достижения числа постов.

## Проверка

`python -m unittest discover -s tests -v` — 43 теста.
Реально проверены публичный JSON-каталог и HTML-карточка LINEMETRIX,
дата запуска, категория, название, обложка и русский текст.
Полный цикл Playwright → Telegram из текущей среды ещё не подтверждён:
запуск Chromium ограничен средой; доступ записи GitHub отсутствует.
Не считать этот архив доказательством установленного обновления.

Для локального preview: Python 3.11+, `pip install -r requirements.txt`,
`python -m playwright install chromium`, `python parser.py`.
Для отправки нужны TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID, затем
`python parser.py --send`. На GitHub их задают существующие Secrets.
Отчёт: preview/report.json; неясный результат отправки не повторяется
автоматически, чтобы не создавать дубли. Диагностика хранится 7 дней.

Argos оставлен как необязательная функция старых адаптеров: для их возврата
потребуются `pip install argostranslate` и `python scripts/install_models.py`.
Профиль Kickstarter использует русский словарь и не скачивает тяжёлые модели.
